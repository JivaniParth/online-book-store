# BookHaven — Online Bookstore (Flask + MySQL)

A **relational-first backend implementation** of the BookHaven online bookstore using Flask and MySQL.

This version prioritizes **data integrity, schema clarity, and transactional safety** over flexibility.

> Part of the **BookHaven System Design Study**  
> 🔗 https://github.com/JivaniParth/BookHaven-System-Design-Study

---

## Purpose

This implementation exists to explore:
- SQL schema design
- ACID transactions
- Relational constraints
- Backend-driven logic

It represents a **traditional, structured backend approach**.

---

## Tech Stack

- Python
- Flask
- SQLAlchemy
- MySQL / SQLite
- JWT authentication

---

## Strengths

- Strong data consistency
- Explicit relationships
- Easier reporting and analytics
- Predictable behavior

---

## Tradeoffs

- Slower iteration speed
- Rigid schema evolution
- More upfront design required

---

## Ideal Use Cases

- Data-heavy systems
- Enterprise backends
- Transaction-critical workflows
